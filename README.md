Super Market Sales Dashboard 📊

 🔍 Project Overview

This project analyzes supermarket sales data to provide insights for business decision-making.

📊 Features

* KPI cards (Total Sales, Quantity, Rating)
* Sales by City, Product Line, Payment Method
* Gender-based insights
* Interactive filters

 💡 Key Insights

* Mumbai has highest sales
* Cash is most used payment method
* Food & Beverages generates highest revenue

 🛠 Tools Used
* Power BI
